# Комната

Клиентский прототип анонимного обмена текстовыми сообщениями. Требуются браузер и Python 3 для раздачи статических файлов.

1. Распакуйте архив и откройте терминал в папке с index.html.
2. Выполните `python -m http.server 8000 --bind 127.0.0.1` (или `python3` вместо `python`).
3. Откройте http://127.0.0.1:8000, нажмите «Создать комнату» и запомните её код.
4. Откройте тот же адрес в новой вкладке через Ctrl+T. Введите код и нажмите «Войти».
5. Отправьте сообщения из обеих вкладок. Обновление страницы сохраняет историю и личность вкладки.

Комнаты и сообщения хранятся как JSON в localStorage. Сведения о текущей комнате и гостевом идентификаторе хранятся в sessionStorage. Создавайте вторую вкладку через адресную строку: при дублировании вкладки браузер может скопировать sessionStorage.

Хранилище доступно вкладкам одного профиля браузера по одному адресу. Переписка между разными устройствами потребует сетевого слоя. Код комнаты служит для выбора истории. Пользователь этого браузера может прочитать данные через инструменты разработчика. После очистки данных сайта комнаты и переписка исчезнут.

## Ключи данных

- `anon-chat:v1:room:<код>` — объект с полями code и createdAt.
- `anon-chat:v1:message:<код>:<UUID>` — объект с полями id, author, text, createdAt.
- `anon-chat:v1:tab` — объект с полями id и room в sessionStorage.

## Список комнат и фото

Панель показывает все комнаты текущего локального хранилища. Нажмите на код в списке, чтобы открыть отдельную историю. Новые комнаты появляются и в других вкладках по тому же адресу.

В диалоге можно выбрать JPEG, PNG или WebP до 8 МБ. Браузер уменьшает фото до 760 пикселей по длинной стороне и сохраняет его как WebP в необязательном поле `photo` JSON-сообщения. Можно отправить фото отдельно или вместе с текстом. Если хранилище заполнено, форма сохраняет черновик. Старые сообщения с одним текстом открываются без изменений.
